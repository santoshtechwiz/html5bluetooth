# Web Bluetooth Device Explorer PWA

A Progressive Web App designed to test and interact with Bluetooth Low Energy (BLE) devices.

## Features
- **PWA Support**: Installable on mobile and desktop.
- **Device Explorer**: Map GATT services and characteristics.
- **Read/Write/Notify**: Full interaction with BLE characteristics.
- **iOS Support**: Optimized for the Bluefy browser on iPhone.

## Setup
1. `npm install`
2. `npm start`
3. Access via `https` (use ngrok for local testing).
